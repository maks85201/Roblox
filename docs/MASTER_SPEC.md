1. ПРОДУКТОВАЯ ЦЕЛЬ И КРИТЕРИИ «УРОВНЯ ТОПОВ»
=====================================================================
1.1 Жанр: кооперативная социальная sandbox-выживалка со строительством, прогрессией предметов и волновыми рейдами. Ядро аудитории 10–16, плюс 18–30 в коопе.
1.2 Целевые метрики (exit-критерии качества):
- Загрузка до играбельности: десктоп < 20 c, мобильные < 30 c.
- FTUE (первая цель выполнена): > 70% установок.
- D1 >= 35%, D7 >= 15%, D28 >= 8%.
- Средняя сессия >= 12 мин; >= 3 сессий в неделю на игрока.
- Crash-free >= 99.5%; клиентских ошибок <= 0.5 на сессию.
- Палец вверх >= 85%.
- Мобильные >= 60% аудитории; FPS >= 55 на среднем телефоне.
1.3 Атрибуты топов, которые закладываем сознательно: веселье за первые 30 секунд; игра с друзьями с первой минуты; видимый прогресс за каждую сессию; социальный статус (база, косметика); контент-дропы каждые 2–4 недели; сильный icon/thumbnail; клипы для TikTok/Shorts; комьюнити (Discord + анонсы в игре).

2. ПОЛНЫЙ ОБЪЁМ ФУНКЦИЙ (ОТ А ДО Я)
=====================================================================
2.1 МИР: хаб-остров + личные участки; 3 биома к запуску (берег, лес, разлом); погода (дождь, туман, шторм как событие); день/ночь; визуальные сезоны.
2.2 FTUE: кораблекрушение за 60 секунд; цель «5 дерева → костёр» за 3 минуты; первая стена за 10 минут; первая волна в первый игровой день; контекстные подсказки Hint AI; режим «ветеран» со скипом туториала.
2.3 СБОР: 6 ресурсов к запуску (дерево, камень, волокно, ягода, кристалл, металл); ноды с истощением и респауном; тиры инструментов ускоряют, но не открывают доступ (нет пейволла).
2.4 РОСТ ПРЕДМЕТОВ И ПРОГРЕССИЯ (всё data-driven в GameConfig):
- Инструменты: дерево → камень → железо → разломный; только крафт, не покупка.
- Растения/культуры: посадка → стадии (росток, рост, спелость) идут в РЕАЛЬНОМ времени, включая офлайн; полив ускоряет; теплица в сезоне 2.
- Питомцы: стадии роста; пассивки — косметика + лёгкая утилита (носка предметов).
- База: уровни 1–10, открывают слоты построек и декора.
- Игрок: сезонный уровень с косметическими наградами.
2.5 СТРОИТЕЛЬСТВО: сетка 4 stud; 20+ деталей к запуску;Blueprints (готовые схемы баз); общая база друзей с ролями (владелец/строитель/гость); рейды только консенсуальные (режим «Штурм форта»).
2.6 БОЙ И ВОЛНЫ: 4 типа врагов + сезонный босс; FSM + групповое поведение; адаптивная сложность (AI Director) с журналом решений; награды — крафт-ресурсы и косметика; штраф смерти — только время.
2.7 СОЦИАЛКА: пати до 6; общие базы; эмоции; быстрые безопасные фразы; гостевой режим; подарки косметики; трейда на запуске НЕТ (анти-скам).
2.8 ИИ (4 слоя): gameplay (FSM, групповая тактика), director (сложность + события-подсказки), hints (контекстные советы по бездействию/провалам), ops (оффлайн-анализ логов и отзывов). Внешний LLM — только после запуска, через серверный прокси с квотами, фильтрами и фолбэком; в MVP не включать.
2.9 АНИМАЦИИ (полный сет + полировка):
- Сет: idle x3, walk/run/back/side, jump/fall/land, swim, chop, mine, pick, hammer (стройка), carry (бревно/ящик), sit (костёр), sleep, emotes (привет, танец x2, указать), combat (swing x2, hit reaction), death, craft, water plant, pet pet.
- Полировка: anticipation и follow-through в ударах; вес через смещение таза; НЕТ скольжения ног (speed matching / root motion); процедурное дыхание и head-look на интерактах; синхрон звука маркерами внутри анимации; приоритеты Idle < Movement < Action < Emote; кроссфейд 0.1–0.2 c; универсальный R15.
- Продакшн: Roblox Animation Editor → rbxanim → AnimationDatabase; звуковые события внутри анимаций.
2.10 ГРАФИКА И АРТ-ДИРЕКШН:
- Стиль: стилизованный «тёплый реализм»: сочная закатная палитра, округлые формы, читаемые силуэты; разлом — неоновый контраст.
- Свет: Technology = Future; рецепт: тёплое солнце днём, холодная луна ночью; Atmosphere density 0.3–0.6; ColorCorrection тёплый lift; Bloom минимальный (на мобильных ВЫКЛ); DOF на мобильных ВЫКЛ.
- Материалы: SurfaceAppearance для стилизованного PBR; кастомные материалы террейна; вода: Future water + каустики-декали.
- Растительность: ручной LOD (3 уровня) + билборды вдали; бюджет плотности на биом.
- VFX: hit сбора, place постройки, дым/искры костра, портал волны, level up, ауры редкости x5, дождь/брызги; бюджет <= 1500 активных частиц одновременно на мобильных.
- Оптимизация: StreamingEnabled; <= 15k видимых частей на остров; <= 8 динамических источников света одновременно на мобильных; атласы текстур; occlusion геометрией.
- Icon/thumbnail: 3 концепта под A/B; сцена «персонаж + база на закате».
2.11 ЗВУК: карта 40+ звуков (сбор x3 на ресурс, стройка x3, UI x6, эмбиент-слои день/ночь/погода, костёр, волны, птицы, сверчки, ветер, враги x4, босс, старт/финиш волны, level up, error, success); микс: эмбиент-слои тише событий, дакинг на важных событиях; ASMR-акценты: дерево, огонь, вода; все источники CC0/лицензия; таблица assets/AUDIO_SOURCES.md.
2.12 UI/UX: дизайн-система (сетка 8px, палитра редкостей, иконки без текста где можно); экраны: HUD (минимум), инвентарь, стройка, крафт, огород, питомцы, магазин-заглушка, настройки (графика/звук/доступность), карта, квесты, фидбек, пауза; доступность: дальтоник-режим (дублирование редкости формой), масштаб текста, размеры кнопок S/M/L; мобильные: thumb-зоны, кнопки >= 44px, игра одной рукой.
2.13 УДЕРЖАНИЕ: 3 дейлика + 3 недельника; сезон 45 дней с косметическим пропуском; ачивки; стрик входов (косметика); коллекция «осколки разлома»; ивент-календарь (шторм выходного дня).
2.14 МОНЕТИЗАЦИЯ (каркас сейчас, включение после запуска): только косметика; пропуск 399–499 R$; подписка «Хранитель» с питомцем месяца; Immersive Ads только как билборды в хабе; НЕТ pay-to-win, НЕТ лутбоксов за реальные деньги.
2.15 БЕЗОПАСНОСТЬ: репорты с категориями; авто-мьют спама; безопасные зоны; анти-гриф через роли гостей; без PII в логах; журнал модер-решений.
2.16 АНАЛИТИКА: таксономия 40+ событий с воронками (install → FTUE → build → wave → D1); sessionId; без PII; недельный экспорт для ops-анализа.
2.17 LIVE OPS: remote config (баланс, флаги); анонсы в игре; дропы каждые 2–4 недели; changelog в игре и в описании; rollback отключением флагов.
